Values are after axis mapping and calibration. Resting |Accel| should sit at 1.000; if it does not, the scale factors are off.

Linear is motion only — the gravity vector, rotated into the body frame by the current attitude, has been subtracted. Held still at any angle it should read near zero; what is left over is calibration error plus whatever the attitude estimate gets wrong.

Axis mapping — body frame is X forward, Y starboard, Z down

Set these so the three checks above all read OK. Mounting the breakout any way but perfectly nose-forward needs a remap here.

Gyro bias (°/s)
Complementary filter weight

How hard gravity pulls roll and pitch back toward the accelerometer reading. Higher follows the accelerometer and is noisier under vibration; lower trusts the gyro and drifts more. 2.0 is a sane start. Heading never gets a correction — there is no magnetometer.

Six-position accelerometer capture

Rest the board with each axis pointing at the sky, hold still, click. Each capture averages 2 s.

Running this

    

      
Flash imu_stream.ino, close the Arduino Serial Monitor (it holds the port), then click Connect and pick the usbmodem port. Needs Chrome or Edge — Safari and Firefox have no Web Serial.

      
If Connect does nothing from a file:// page, serve it instead: python3 -m http.server 8000 in this folder, then open http://localhost:8000/imu_live.html.

      
No hardware yet? Tick simulated data to drive the whole page from a synthetic sensor with built-in bias and scale error.
